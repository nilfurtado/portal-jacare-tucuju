================================================================================
                          COMO USAR CADA RECURSO
================================================================================

1. ORDENAÇÃO
   Clique em "Usuário ↕" → ↑ (A-Z) → ↓ (Z-A) → ↕ (novo campo)

2. PAGINAÇÃO
   Clique [← Anterior] / [Próximo →]
   Veja "Página X de Y"

3. BULK ACTIONS
   ☑ Checkbox → Barra aparece → Clique "Deletar" → Confirme

4. EXPORTAR
   Clique "Exportar" → Escolha JSON ou CSV → Download automático

5. HISTÓRICO
   Clique ⏰ em uma linha → Modal mostra alterações

6. AVATAR
   Clique 📷 em uma linha → Arraste/clique foto → Salvar
