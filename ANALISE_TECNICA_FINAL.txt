HIPÓTESES DO PROBLEMA RAIZ
─────────────────────────────────────────────────────────────────────────────────

HIPÓTESE 1: CACHE DO NAVEGADOR (PROBABILIDADE: 85%)
├─ Se usuário acessou ANTES de 14:08 do dia 4 de junho
├─ Navegador salvou versão ANTIGA (painel-php) em cache local
├─ Cache tem 5 minutos (max-age=300), dependendo de quando foi acessado
├─ Se cache ainda está fresco, navegador NÃO faz requisição ao servidor
├─ Resultado: Usuário vê versão ANTIGA com CSS mínimo e "${classe}" literal
└─ Confirmação: curl mostra correto mas navegador mostra errado

COMO VERIFICAR:
  F12 → Network → Limpar → Recarregar F5
  Procurar por anuncios.html
  Se status é 304 (Not Modified) = cache estava fresco
  Se status é 200 = novo download do servidor

HIPÓTESE 2: ERRO DE JAVASCRIPT EM TEMPO DE EXECUÇÃO (PROBABILIDADE: 10%)
├─ Erro ao importar /js/shell.js ou outro módulo
├─ Erro ao chamar document.getElementById('slot-grid')
├─ Erro ao chamar await mountShell()
├─ Resultado: Página carrega mas grid fica em "Carregando slots..."
└─ Grid nunca é populado com dados

COMO VERIFICAR:
  F12 → Console
  Procurar por erros em VERMELHO
  Executar: document.getElementById('slot-grid')
  Deve retornar: <div class="slot-grid stagger" id="slot-grid">...</div>
  Se retorna null = problema mais grave

HIPÓTESE 3: AUTENTICAÇÃO EXPIRADA (PROBABILIDADE: 3%)
├─ localStorage['painel-dm:token'] está vazio ou expirado
├─ requireAuth() em shell.js detecta isso
├─ Página redireciona para /painel/login/
├─ Resultado: Usuário é forçado a login novamente
└─ Pode parecer que página não funciona

COMO VERIFICAR:
  F12 → Application → Local Storage → http://localhost:3000
  Procurar por chaves: painel-dm:token, painel-dm:user
  Se vazias = precisa fazer login

HIPÓTESE 4: PROXY HTTP INTERMEDIÁRIO (PROBABILIDADE: 2%)
├─ nginx, Apache, ou outro proxy entre cliente e servidor
├─ Proxy tem cache próprio servindo versão antiga
├─ Resultado: curl localhost:3000 mostra correto,
│            mas navegador (em IP diferente) vê versão antiga
└─ Problema no nível de infraestrutura

COMO VERIFICAR:
  Verificar nginx.conf ou Apache config
  Procurar por proxy_cache_path ou CacheEnable
  Limpar cache do proxy: service nginx reload
